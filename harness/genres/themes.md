# 主題（`theme`）

> 主題的通用清單（ADR-0026 §3.2）。每篇文章只有一個主題，slug 寫進 front matter 的 `theme`；跨兩個主題時，選讀者做決定時最在意的那一個。
> 一個角色用哪幾個主題、對每個主題怎麼看，是那個角色的資料，寫在角色資料夾的 `themes.md`，不寫在這裡。
> 主題不是網站的分類：發布到哪裡、歸哪一類是發布那一層的事。
> 這個檔不是文體定義：程式讀文體時會跳過它（`Harness.genre_files`）。

| slug | 說明 |
| :--- | :--- |
| `worldview` | AI 時代的工作與職涯 |
| `builder-method` | 做產品的方法與工程實務 |
| `startup` | 新創的賽道與產品拆解 |
| `tech-selection` | 技術選型 |
| `adoption` | 落地導入與失敗復盤 |
| `education` | 決策原理與實作教學 |
| `tools` | 工具與工作流程選型 |
| `open-source` | 開源專案與技術演進 |
