# ADR-0002：模型分工 — Qwen 產問題、Opus 規劃與複核、Sonnet 寫作

> **狀態：** 已接受（R5 重新評估） | **日期：** 2026-10-10 | **決策者：** 專案擁有者
> 依 `docs/templates/vibecoding/04_architecture_decision_record_template.md` 撰寫。

## 1. 背景與問題

- **上下文：** 流程有四類工作：產候選問題（量大、要快）、研究規劃與證據複核（要判斷力）、長文寫作（要文筆、量大）、搜尋（交給 Tavily）。
- **問題：** 全部用最強的模型太貴，全部用便宜的模型品質撐不住。每個節點的提示詞、輸出 schema 和評分標準都會依模型調整，換模型就要重調，所以分工一旦定下來，改起來是有成本的。
- **驅動因素：** 每篇成本可控（`brief.md` §5.1，基準約 US$0.64）；反證與來源審查的品質。
- **約束：** 本機有一張 3090；雲端用 Anthropic API。

## 2. 考量的選項

| 組 | 組合 | 優點 | 缺點 |
| :--- | :--- | :--- | :--- |
| A | Qwen 規劃＋Sonnet 寫 | 最便宜 | 規劃與反證的判斷力存疑 |
| **B** | Qwen 產問題＋Opus 規劃與複核＋Sonnet 寫 | Opus 只用在最需要判斷的兩個節點 | 要維護三種模型的提示詞 |
| C | Opus 全程研究＋Sonnet 寫 | 研究品質上限最高 | 成本最高；產候選問題用不到 Opus 的能力 |

## 3. 決策

**選擇：** B。

| 節點 | 模型 | 為什麼 |
| :--- | :--- | :--- |
| Scout（候選問題） | Qwen3.5 9B，本機 Ollama | 量大、要快，沒有按量 API 費 |
| Director（研究規劃） | Opus 5.5 | 要提出競爭假說、反證路徑，判斷力最重要 |
| Reviewer（證據複核） | Opus 5.5 | 逐條核對主張與來源，錯放的代價最高 |
| Writer（大綱與長文） | Sonnet 5.5 | 長文 token 多，Sonnet 單價是 Opus 的一半 |

**理由：** 把最貴的模型只放在「錯了代價最高」的兩個節點。B 是一個**要被實驗驗證的假設**，不是定論。

## 4. 後果

- **正面：** 依 2026-10-10 的官方單價，每篇雲端 LLM 約 US$0.50（Opus US$0.28＋Sonnet US$0.22）。
- **負面：** 三種模型、四套提示詞要各自做版本管理；本機 Qwen 多了一個要維運的 Worker。
- **影響範圍：** Prompt registry、成本計量、部署（本機 GPU Worker）。
- **重新評估觸發：** **R5 的 A/B/C 實驗**（`brief.md` §5.2）。B 沒有明顯勝過 A，就拿掉 Opus 的兩個節點，另寫一份 ADR 覆蓋這份。模型單價或可用性大幅變動時也要重評。
